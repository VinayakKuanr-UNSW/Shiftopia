## Hard rules / gotchas
- Root font is 75% (`src/index.css`): `h-11` = 33px and `text-xs` = 9px. Write physical minimums in px: `h-[44px]` for targets, `text-[11px]` as the type floor, `text-[16px]` for phone inputs.
- Global Scope (`PersonalPageHeader`, `GlobalScopeFilter`, `CommandSelector`) is PROTECTED. Never restyle it.
- Dark-mode blur: use `dark:backdrop-filter-none`, NOT `backdrop-blur-none`. A `blur(0)` filter still traps `position:fixed` children.
- Radix `data-state` on-colours need a `dark:` variant, or the off colour wins in dark mode.
- Verify a test against old code with `git show HEAD:path`. Never `git stash`: the user owns `stash@{0}`.
- Check the real tsc exit code (redirect output to a file), not `| head`.
